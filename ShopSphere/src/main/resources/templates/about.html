About ShopNest

ShopNest is a comprehensive, production-grade E-Commerce web application developed strictly using Java, Spring Boot 3, Thymeleaf, and an offline H2 database.

Java 17 & Spring Boot

Spring Boot 3.2 serves as the core framework orchestrating dependency injection, Spring MVC controllers, and embedded Tomcat server.

H2 Database Engine

Zero-configuration, file-based embedded SQL database (`shopnestdb.mv.db`) supporting transactions, relations, and offline execution.

Thymeleaf & Bootstrap

Server-Side Templating Engine seamlessly rendering dynamic HTML5 with Bootstrap 5.3 and custom responsive CSS.

Admin Management

Dedicated role-based administrator panel for real-time inventory management (CRUD) and customer order lifecycle tracking.

System Architecture & Database Design

Database Tables in H2:
  • products: SKU, Name, Description, Price, Category, Stock, Image, Rating
    16+ Items
  • users: Full Name, Email, Password, Role (ADMIN/CUSTOMER), Phone
    Auth
  • cart_items: Session ID, Product ID, Quantity, Added Timestamp
    Session Persistent
  • orders: Order ID, Order No, Customer, Address, COD, Status, Total
    Orders
  • order_items: Order Reference, Product Reference, Price, Qty, Subtotal
    Line Items
Key Features Implemented:
Search & Filter: Real-time category filtering and keyword matching.
Persistent Cart: Database backed session cart with inventory capping.
Cash on Delivery (COD): Clean checkout with address validation.
Automatic Seeding: Automatic insertion of 16 sample products on first boot.
Admin Dashboard: Product CRUD and Order status tracking.
